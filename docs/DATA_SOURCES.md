# Data sources

Constants and the Solar System preset cite the page they were taken from. Test fixtures record the retrieval date.

| Quantity | Source |
| --- | --- |
| G, Stefan-Boltzmann | CODATA 2018 |
| Astronomical unit | IAU 2012 Resolution B2 |
| Nominal solar radius, luminosity, temperature | IAU 2015 Resolution B3 |
| GM of the Sun, Earth, Moon | JPL DE440, [Astrodynamic Parameters](https://ssd.jpl.nasa.gov/astro_par.html) |
| Planetary elements 1800–2050 | [JPL approximate positions](https://ssd.jpl.nasa.gov/planets/approx_pos.html), Table 1 |
| Planetary masses, radii, rotation | [NASA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) |
| Reference positions | [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) (DE441) |
| Seasons | [USNO seasons API](https://aa.usno.navy.mil/data/api) |
| Eclipses | [NASA GSFC eclipse catalog](https://eclipse.gsfc.nasa.gov/SEdecade/SEdecade2021.html) |
